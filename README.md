# По пути

Учебный MVP сервиса поиска попутчиков. React 19, TypeScript, Vite, Zustand (persist), TanStack Router, Framer Motion, Radix Dialog, кнопка shadcn/ui, Tailwind CSS 4, clsx / tailwind-merge, Lucide.

## Запуск

```sh
npm install
npm run dev
```

`npm run build` проверяет типы и создаёт production-сборку.

## Возможности

Поиск по городам, дате и числу пассажиров; стилизованный календарь React Day Picker + Radix Popover; создание поездки; демо-бронирование; мои поездки; чаты; профиль с автомобилем, проверками, отзывами и рейтингами водителя/пассажира; редактирование имени; светлая и тёмная темы; демо-вход по почте, Госуслугам и MAX.

Все данные тестовые. Авторизация не проверяет пароль и не создаёт защищённую сессию. Паспортная проверка и интеграции имитируются. Не вводите настоящие документы или пароли. Состояние хранится в localStorage. Чтобы сбросить демо, очистите localStorage. Для реального приложения потребуются backend, OAuth, разграничение доступа и проверка документов. Фото загружаются с Unsplash; для офлайн-версии замените локальными изображениями. Чат представляет локальную демонстрацию и не отправляет сообщения другим людям.
